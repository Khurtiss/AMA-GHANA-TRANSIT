# 🇬🇭 GHANA TRANSIT — Lecturer Submission Guide

This project is a ReactJS-based transport aggregation platform. It has been built using standard React patterns and modern CSS to ensure it is both robust and visually impressive for presentation.

## 🛠️ Technology Stack
- **Languages**: HTML5, CSS3, JavaScript (ES6+), ReactJS
- **Icons**: Lucide React
- **Styling**: Bootstrap 5 + Custom Modern CSS
- **Routing**: React Router (HashRouter for easy static serving)

## 🚀 How to Run the Project

### Option 1: Standard Development Mode (Recommended for Code Review)
Ensure you have [Node.js](https://nodejs.org/) installed, then:
1. Open the project folder in your terminal.
2. Run `npm install` to install dependencies.
3. Run `npm start` to start the development server.
4. Open the link (usually http://localhost:3000) in your browser.

### Option 2: Pre-built Static Version (No Installation Required)
If you want to view the project immediately without running commands:
1. Open the `/dist` folder.
2. Open `index.html` in any modern web browser. 
   *(Note: Some browsers block local file execution for React apps. If it appears blank, please use 'Option 3' below or serve the 'dist' folder via a simple live server).*

### Option 3: Quick Live Server
If you have Python installed:
1. Go to the project root.
2. Run `python -m http.server 8000`.
3. Visit `http://localhost:8000/dist/index.html`.

## 📂 Project Structure
- `/src`: Contains all React source code.
- `/src/dashboards`: Portal implementations (Passenger, Operator, Admin).
- `/src/pages`: Main landing and functional pages.
- `/src/components`: Reusable UI components.
- `/src/assets`: Images and branding assets.
